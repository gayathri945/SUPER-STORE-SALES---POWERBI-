This project presents an interactive Power BI dashboard that visualizes superstore sales performance.
It provides insights into sales, profit, shipping, and payment modes across different categories, subcategories, regions, and time periods.

Objectives

- Analyze total sales and profit trends over time

- Compare sales performance across categories and subcategories

- Track the most used shipping modes and payment types

- Study regional sales performance

- Forecast upcoming sales using available data

Tools Used

- Power BI Desktop – Data visualization and report creation

- Microsoft Excel / CSV – Data preprocessing and cleaning
